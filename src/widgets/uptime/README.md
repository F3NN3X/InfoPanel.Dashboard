# Uptime

Time since boot.

## What it shows

The time since the PC booted, as days, hours, minutes and seconds. Small zones get a summary card.

## Data it needs

The system info plugin's uptime, `plugins.system-info-plugin.uptime.*` (it owns that prefix): `days`, `hours`, `minutes`
and `seconds`. Nothing to pick or bind.

## Options

- **Seconds**: show the seconds.

## Presets

None yet.
