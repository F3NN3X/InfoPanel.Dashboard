# Achievements

Achievement progress for this game.

## What it shows

The current game's completion as a ring or pips, unlocked out of total, and the latest unlock. A summary card; the dense
view falls back to it. It sends to the Dynamic Island.

## Data it needs

The Steam API plugin, `plugins.InfoPanel.SteamAPI.SteamAPI-Achievements.*` (`achievements-unlocked`,
`achievements-total`, `latest-achievement`), and `SteamAPI-Session.current-game` (read, not owned). It owns no prefix.

## Options

- **Progress display**: Ring or Pips.
