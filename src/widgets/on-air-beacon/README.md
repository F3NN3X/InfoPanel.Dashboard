# On-Air Beacon

Live, recording or off air, from OBS.

## What it shows

A large LIVE, REC or Off air state with how long it has been going. No summary card and no dense view.

## Data it needs

The OBS connection under Settings › Connections (served by the server, not sensor keys). It draws without sensor keys.

## Options

- **Elapsed time** and **Count seconds**.
- **Live** and **Recording**: the colours (the theme's Critical and Warning unless set).

None yet.
