# Timer

A countdown with presets and a pomodoro.

## What it shows

A countdown with preset buttons for screens you can touch, and an optional pomodoro that alternates focus and break rounds
until stopped. It sends its countdown to the Dynamic Island.

## Data it needs

No sensor keys: it keeps its own timer state, and draws without sensor keys.

## Options

- **Presets (minutes)**: the buttons, comma separated.
- **Pomodoro button**, with **Focus (min)** and **Break (min)**.
