# Steam Profile

Avatar, status and friends online.

## What it shows

The avatar, persona name, status and level, and with room the friends online and in-game with recent activity. Small zones
get a summary card.

## Data it needs

The Steam API plugin, `plugins.InfoPanel.SteamAPI.SteamAPI-Profile.*` and `plugins.InfoPanel.SteamAPI.SteamAPI-Social.*`
(it owns both prefixes).

## Options

None of its own: the Data tab shows where the profile comes from.
