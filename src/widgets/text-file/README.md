# Text File

A watched text file, live.

## What it shows

The file's text, with a header line of its size, line count and any status that names a problem. Small zones get a
summary card and a dense view of their own.

## Data it needs

The TextFile plugin, `plugins.InfoPanel.TextFile.*`: `content`, `status`, `file-size` and `line-count`.

## Options

- **Size / lines / status header**.

## Presets

None yet.
