# Web Page

A web page or video in a frame.

## What it shows

A web page, or a YouTube video made embeddable, in a frame that fills the widget. No header and no small-zone views.

## Data it needs

None: it reads a URL and no sensor keys, so its Data tab is empty and it draws without sensor keys.

## Options

- **URL**.
- The look subset: an accent colour, size and corners, and the frame's edge.

## Presets

None yet.
