# Network Adapters

IP address and link speed per adapter.

## What it shows

The public IP, then each adapter's status, link speed, IPv4 and IPv6 addresses. Small zones get a summary card and a dense
view of their own.

## Data it needs

The network info plugin, `plugins.network-info-plugin.*` (it owns the prefix).

## Options

- **Show adapters that are down**.
- **IPv6 count**: Large sizes, Show or Hide.
- **Blur addresses**.
