# Game News

Headlines for your games.

## What it shows

The latest headlines for the current game and your library; long titles clamp to the **Title lines** you set. Small zones get
a summary card and a dense view of their own. It sends to the Dynamic Island.

## Data it needs

The Steam API plugin's news container, `plugins.InfoPanel.SteamAPI.SteamAPI-News.*` (`library-news`,
`current_game_news_title`), and `SteamAPI-Session.current-game` (read, not owned). It owns no prefix.

## Options

- **Title lines**: 1 to 4.
