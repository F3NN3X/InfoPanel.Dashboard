# Notifications

The latest notification and its history.

## What it shows

The latest toast notification with the count, and the history list (time, type and message; errors and warnings in their
own colours). Small zones get a summary card and a dense view of their own. It can send the latest to the island.

## Data it needs

The Notifications plugin, `plugins.InfoPanel.Notifications.*`: `notification-count`, `last-notification`,
`notification-history` and `status`.

## Options

- **History list**.
- **Max history lines**.
