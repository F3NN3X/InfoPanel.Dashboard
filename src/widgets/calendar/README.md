# Calendar

The month with today marked.

## What it shows

The month's grid with today marked and the week number; under 120 px tall, the current week only. No header; small zones
get a summary card (a 2x2 draws the day and the week itself).

## Data it needs

The clock plugin's date, `plugins.clock-plugin.clock.day`, `month` and `year` (read, not owned: Clock owns the prefix).
It draws without sensor keys too.

## Options

- **Week starts on**: Monday or Sunday.
