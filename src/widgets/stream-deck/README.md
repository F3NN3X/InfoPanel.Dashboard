# Elgato Stream Deck

A virtual Stream Deck with real keys.

## What it shows

A virtual Elgato Stream Deck: its keys come from the Stream Deck app, a press runs the real action. Turn it on under
Settings › Connections, then pick or create a device. Small zones get a summary card and a dense view of their own.

## Data it needs

The server's Stream Deck state (`src/lib/streamdeck.ts`), not sensor keys.

## Options

- **Device** and **Grid**; **Titles**, **Title size**, **Page row** and **Swipe to change page**.
- **Key look**: gap, corner radius, key style, frame, icon overlay and strength, pressed effect.
