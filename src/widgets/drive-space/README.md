# Drive Space

Used and free space per drive.

## What it shows

Each volume's label, type, file system and used/free space, as a list, segmented fill bars or slim bars. The drive row can
carry an emblem or your own image. Small zones get a summary card and a dense view of their own.

## Data it needs

The drive info plugin, `plugins.drive-info-plugin.*` (it owns the prefix).

## Options

- **View**: List, Segments or Bars; **Drive**: pin one volume (Auto lists all); **Sort**: by usage or by name.
- **Neutral below thresholds** (List only) and the **Full** thresholds.
- **Drive icons**: your own image or an icon for each drive.
