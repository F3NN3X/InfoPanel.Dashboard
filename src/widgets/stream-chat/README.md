# Stream Chat

Live Twitch chat with a send box.

## What it shows

Live chat with badge squares, name colours, viewer count, @mention highlight and an optional send box. Sign in under
Settings › Connections. Small zones get a summary card and a dense view of their own.

## Data it needs

The server's chat connection (`src/lib/chat.ts`, Twitch and YouTube), not sensor keys.

## Options

- **Source**: Twitch, YouTube or Both, and **Send to** when Both.
- **Highlight name**, **Show send box**, **Text size** and **Messages shown**; **Name colours**.
