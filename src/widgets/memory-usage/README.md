# Memory

Physical and virtual memory in use.

## What it shows

Physical and virtual memory: the load as a ring or bar with a short history, and the used and available gigabytes. Small
zones get a summary card.

## Data it needs

LibreHardwareMonitor (or HWiNFO through its aliases): `libre.total_memory_memory`, `total_memory_memory_used` and
`total_memory_memory_available`, and `libre.virtual_memory_memory`, `virtual_memory_memory_used` and
`virtual_memory_memory_available`.

## Options

- Thresholds: the Load threshold (warning and critical).
