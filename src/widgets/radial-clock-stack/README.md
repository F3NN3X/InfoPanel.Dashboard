# Radial Clock Stack

Day, year, a sensor and the next event as rings.

## What it shows

Concentric rings for how far the day and the year (or week) have gone, optionally the second, one sensor and the time to the
next calendar event, with the time in the middle. Small zones get a summary card and a dense view of their own.

## Data it needs

The clock only, plus the calendar links set under Settings › Connections (served by the server) for the event ring, and
any one sensor key the user picks for the sensor ring. It draws without sensor keys too.

## Options

- **Second ring**: Year or Week, and **Week starts**.
- **Sensor ring**, with where it is empty and full.
- **Next event ring**, with its run-up in minutes.
- **Seconds ring**.
- Units & format: the clock format.
