# Steam Library

Games owned and recent playtime.

## What it shows

Games owned, total and two-week playtime, the recent games with their hours and, at large sizes, game news. A summary card;
the dense view falls back to it.

## Data it needs

The Steam API plugin, `plugins.InfoPanel.SteamAPI.SteamAPI-Library.*` and `SteamAPI-News.*` (it owns both).

## Options

- **News list**: Auto (large only), On or Off.
