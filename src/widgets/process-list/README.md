# Processes

Top processes by CPU or memory.

## What it shows

The top processes by CPU, CPU utility or memory, with the process, thread and handle counts. The sort can be switched on
the widget. Small zones get a summary card and a dense view of their own.

## Data it needs

The system info plugin's process list, `plugins.system-info-plugin.processes.*` (it owns that prefix): the processes'
names, CPU and memory, `cpu-usage`, `cpu-utility`, `thread-count` and the process and handle counts.

## Options

- **Rows**: how many processes; 0 fits the height.
- **Sort by**: CPU, CPU utility or Memory (Behaviour).
