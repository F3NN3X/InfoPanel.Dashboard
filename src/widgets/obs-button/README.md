# OBS Button

Switch scene, mute the mic or save a replay.

## What it shows

A tile that switches OBS to a scene, flips the mic's mute or saves the replay buffer. It rings while its scene is on air
and lights while the mic is muted. It has no summary card or dense view.

## Data it needs

The server's OBS connection (`useExtras().obs`, acting through `src/lib/obs-control.ts`), not sensor keys.

## Options

- **Action**: Switch scene, Mute the mic or Save replay; the **Scene**.
- **Name** and **Symbol** (a Material Symbols name).
