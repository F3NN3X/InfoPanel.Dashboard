# Skins

A skin restyles **chrome, typography, graphs and meters** for every widget at once. Pass `skin` per widget or once per profile. `surface`, `graph`, `meter` and `accent` props override the skin's defaults (`auto` = use the skin's).

|---|---|---|---|---|---|---|

| [`fluent`](skins/fluent.md) | mica | 8 | prop | Segoe UI Variable Display | line | bar |
