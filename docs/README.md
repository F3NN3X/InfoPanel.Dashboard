# Documentation

The project overview, install steps and server endpoints are in the [top-level README](../README.md). Help for
using the app is inside the app itself (the Help view).

- [Customization guide](customization-guide.md) - making a widget look the way you want from the studio: scaling,
  alignment, colours, borders, custom CSS, themes and backgrounds, fonts, and the Dynamic Island.
- [Widget catalog](module-catalog.md) - every widget, its picker name, size, data keys and options, its presets, and the
  recipe and code widgets you can add on the Widgets page.
- [Writing a code widget](code-widgets.md) - for authors: the package, the bundle's contract, signing, the publisher rule and how
  a signed widget reaches a screen.
- [Security model](security.md) - the trust model (this computer, the LAN, widget content), how the desktop app and
  the server are protected, and what was reviewed, fixed and deferred.
- [Desktop app](desktop/README.md) - building the installer, where its settings and logs live, and debug mode.
